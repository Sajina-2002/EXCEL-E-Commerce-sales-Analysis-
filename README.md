
# 📊 E-Commerce Sales Dashboard (Microsoft Excel)

## Overview

This project is an interactive **Microsoft Excel Dashboard** developed to analyze and visualize e-commerce sales performance. It demonstrates Excel's data analysis capabilities using Pivot Tables, Pivot Charts, formulas, and dashboard design techniques to generate business insights from raw sales data.

---

## Features

* Interactive sales dashboard
* Pivot Tables for dynamic data analysis
* Pivot Charts for visual reporting
* KPI summaries
* Product performance analysis
* Customer and store insights
* Descriptive statistics
* Lookup functions (VLOOKUP)
* Clean and organized workbook structure

---

## Dataset

The workbook contains the following sheets:

| Sheet Name              | Description                                |
| ----------------------- | ------------------------------------------ |
| Customer_Dim            | Customer information                       |
| Product_Dim             | Product details                            |
| Store_Dim               | Store information                          |
| Sales_Fact              | Main sales transaction dataset             |
| VLOOKUP                 | Lookup function examples                   |
| Descriptive Statistics  | Statistical summary of the dataset         |
| Dashboard               | Interactive dashboard with KPIs and charts |
| Pivot Tables and Charts | Supporting Pivot Tables and Pivot Charts   |
